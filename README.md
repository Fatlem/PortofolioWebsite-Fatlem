# Portfolio Website

Sebuah website portfolio modern untuk web developer dengan design responsif dan animasi yang menarik.

## ✨ Fitur

- 🎨 **Design Modern**: Dark theme dengan aksen cyan yang elegan
- 📱 **Fully Responsive**: Optimal di semua device (desktop, tablet, mobile)
- 🎭 **Smooth Animations**: Loading screen, fade-in, hover effects, dan scroll animations
- 🚀 **Performance Optimized**: Clean code dan fast loading
- 🎯 **SEO Friendly**: Semantic HTML dan structured data
- 📧 **Contact Form Ready**: Siap untuk integrasi dengan backend
- 🎪 **Interactive Elements**: Hover effects dan smooth scrolling

## 🏗️ Struktur File

```
portfolio-website/
├── index.html              # File HTML utama
├── css/
│   ├── style.css          # CSS utama
│   └── responsive.css     # CSS responsive design

├── images/

│   ├── project1.jpg      # Screenshot project 1
│   ├── project2.jpg      # Screenshot project 2

└── README.md
```

## 🚀 Cara Penggunaan

1. **Clone atau download** repository ini
2. **Ganti content** dengan informasi personal Anda:
   - Nama, title, dan deskripsi di section Hero
   - Foto profil di folder `images/`
   - Informasi About section
   - Detail project dan screenshot
   - Informasi kontak dan social media links
3. **Upload gambar** Anda ke folder `images/`
4. **Customize colors** jika diperlukan di `css/style.css`
5. **Deploy** ke hosting pilihan Anda

## 🎨 Kustomisasi

### Mengubah Warna
Ubah variabel warna di `css/style.css`:
```css
/* Primary color */
#00d4ff -> warna pilihan Anda

/* Background colors */
#0f0f0f -> dark background
#1a1a1a -> medium background
#2a2a2a -> light background
```

### Menambah Project
Duplikasi struktur HTML project card di `index.html`:
```html

    
        
        
            
                
                
            
        
    
    
        Nama Project
        Deskripsi project...
        
            Technology 1
            Technology 2
        
    

```

### Menambah Skills
Tambah skill baru di section About:
```html

    
    Skill Name

```

## 📁 File Details

### index.html
File HTML utama yang berisi struktur website dengan sections:
- Navigation
- Hero section
- About section
- Projects section
- Contact section
- Footer

### css/style.css
CSS utama yang berisi:
- Base styles dan reset
- Layout dan typography
- Color scheme
- Animations
- Component styles

### css/responsive.css
CSS khusus untuk responsive design:
- Mobile styles (768px and below)
- Tablet styles (1024px and below)
- Small mobile (480px and below)
- Large screen optimizations

### js/main.js
JavaScript utama untuk:
- Loading screen
- Navigation handling
- Mobile menu toggle
- Smooth scrolling
- Form handling
- Back to top button

### js/animations.js
JavaScript khusus untuk animasi:
- Intersection Observer untuk scroll animations
- Typewriter effect
- Parallax scrolling
- Skill animations
- Project hover effects
- Progress indicator

## 📝 Customization Tips

1. **Foto Profil**: Gunakan foto dengan aspect ratio 1:1 atau 4:5
2. **Project Screenshots**: Gunakan ukuran konsisten (misal: 600x400px)
3. **Loading Time**: Optimize images untuk web (format WebP recommended)
4. **SEO**: Tambahkan meta tags untuk description, keywords, dan Open Graph
5. **Analytics**: Integrasikan Google Analytics atau analytics tool lainnya
